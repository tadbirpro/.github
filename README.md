# Tadbir Pro GitHub Defaults

This repository defines the default GitHub community health files, Issue Forms, pull request template, and public organization profile for repositories in the `tadbirpro` organization.

## Repository visibility

GitHub requires the organization-level `.github` repository to be **public**. All other Tadbir Pro repositories are private, and they still inherit these defaults: GitHub applies them regardless of the destination repository's visibility.

Links in these files that point to private repositories (for example the wiki) only work for organization members. That is expected, because only members can open issues and pull requests in private repositories.
